Ivoire 2.7 — new theme on top of Jamra 2.6.1
Branch ivoire-2.7, created from jamra-2.6.1. Jamra and every older theme are untouched and still selectable.

What it is
- New theme id `ivoire` (picker: "Ivoire"), selectable from the native theme picker, from the Jamra theme list and from Ivoire's own settings.
- Ported from the approved mockup in design/ivoire (light editorial: ivory paper, bordeaux/brass ink, Playfair Display + Amiri + IBM Plex Sans Arabic, arch posters, viewfinder focus).
- Isolated Shadow DOM renderer `app/ivoire.js` on the same 1920x1080 stage, fed with live provider data through the existing APJamra bridge (snapshot/act). Native video stays underneath for playback.
- Owner layout rules: main menu is a vertical sidebar on the LEFT; Live TV categories are a vertical column left of the channel list with a preview monitor on the right; Movies/Series categories are a vertical column left of the grid.
- Day "Ivoire" / night "Nocturne" mode and 4 ink colours (Bordeaux, Émeraude, Laiton, Marine) stored in localStorage (ap-ivoire-mode / ap-ivoire-accent).
- Account/activation/playlists open the native settings screen (same as Jamra).

Files
- app/ivoire.js, app/ivoire-style.txt — generated by design/ivoire/renderer/gen.py from design/ivoire/src/style.css + renderer/extra.css + renderer/ivoire.src.js. Edit the sources, then run `python3 design/ivoire/renderer/gen.py`.
- app/assets/ivoire/ — offline fonts (SIL OFL 1.1), declared in app/style.css.
- app.js: theme list + snapshot gains seriesHome/liveHome. red.js: Jamra theme list includes ivoire. index.html: picker button + script. build.cjs: ivoire.js bundled, ivoire-style.txt hash added to CSP. appinfo 2.7.0.

Verification (headless Chromium, mocked panel + Xtream provider, built dist with hash-only CSP enforced)
- npm run check: 30 pass.
- tests/ivoire27-flow.py: home, live, player-live, channel drawer, movies, movie detail, series, series detail + episodes, series player, settings, night mode, Back from every screen — 0 runtime errors.
- tests/ivoire27-remote.py: 150 random D-pad presses across the 5 tabs, focus never lost; switching ivoire <-> jamra hides/shows the right renderer.
- Not tested on a physical LG TV or a real provider. No .ipk built here (ares-package not available in this environment).
